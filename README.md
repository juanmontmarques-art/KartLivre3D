# Kart Livre 3D

Protótipo inicial de um jogo de kart 3D cartoon para Android, feito em Godot 4.

## O que existe nesta primeira base
- Arena de treino 3D simples
- Kart feito com formas primitivas
- Câmera em terceira pessoa
- Aceleração, freio e direção
- HUD com velocidade e cronômetro
- Botões táteis iniciais e controles de teclado para testar no computador

## Como abrir
1. Instale/abra Godot 4 em um ambiente compatível.
2. Importe a pasta deste projeto pelo arquivo `project.godot`.
3. Execute `Main.tscn`.

## Controles
- W ou seta para cima: acelerar
- S ou seta para baixo: frear/recuar
- A/seta esquerda: virar à esquerda
- D/seta direita: virar à direita

## Estado
Esta é uma base de protótipo, não um jogo final. A interface tátil, colisões de pista, menu, arte, áudio e exportação Android precisam de testes e melhorias em Godot antes de publicar.
